# Online Complaint Registration System

## Project Description

The Online Complaint Registration System is a web application that allows users to register complaints online and track their status. Administrators can view complaints and update their status.

## Features

* User Complaint Registration
* Complaint Tracking
* Admin Dashboard
* Status Updates
* User-Friendly Interface

## Technologies Used

* HTML
* CSS
* JavaScript
* Node.js (Future Enhancement)
* MySQL (Future Enhancement)

## Project Structure

* index.html
* style.css
* script.js

## How to Run

1. Download the project files.
2. Open index.html in a web browser.
3. Fill out the complaint form.
4. Submit the complaint.
